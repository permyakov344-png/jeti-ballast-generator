JETI BALLAST GENERATOR — КАК ПОЛЬЗОВАТЬСЯ
========================================

Что это
-------
Превращает Excel-таблицу с вариантами балласта в Lua-приложение
для передатчика Jeti DC-24 / DS-24.

В архиве:
  jeti_lua_generator.html   — сам генератор (открыть двойным щелчком)
  xlsx.full.min.js          — библиотека чтения Excel (нужна рядом с HTML)
  ballast_template.xlsx     — пустой шаблон для заполнения
  PIKEF3F.lua               — готовые скрипты, можно сразу на SD-карту
  PIKEX.lua
  DEVICE26.lua


Быстрый путь (5 минут)
----------------------
1. Открой ballast_template.xlsx, заполни жёлтые ячейки.
   Строка 1  : B1 — название модели; F1 и правее — подписи снарядов (45/98).
   Строка 2  : шапка № | НОС | КРЫЛО | CG | ВЕС (не менять).
   Строка 3+ : по ДВЕ строки на вариант — сверху НОС, снизу НОС низ.

2. Открой jeti_lua_generator.html, перетащи туда свой .xlsx.

3. В поле перед кнопкой поправь имя файла (до 8 символов, латиница),
   например PIKEF3F, потом нажми кнопку — скачается .lua.

4. Скопируй .lua в папку /Apps/ на SD-карте передатчика.

5. На передатчике: Menu → Applications → выбрать скрипт.
   UP / DOWN — листать страницы, ESC — выход.


Правила заполнения
------------------
- Один лист = одна модель.
- Номер варианта (№) обязателен: без него строка не попадёт в таблицу.
- Кириллицу в значения не писать — экран передатчика её не покажет.
  Известные слова сокращаются автоматически: красный → KRASN, черный → CHERN.
- Подписи вида 45г/98 превращаются в 45/98.
- Листы без вариантов (например «Расчет») генератор просто пропускает.


Если генератор не открывается
-----------------------------
- Файл xlsx.full.min.js должен лежать в той же папке, что и HTML.
  Если его нет, генератор попробует взять библиотеку из интернета.
- Ничего не скачивается — проверь, что имя файла не пустое и в нём
  только латинские буквы и цифры.


Если что-то не работает на передатчике
--------------------------------------
- Пустое место вместо названия — в таблице кириллица.
- Скрипта нет в списке — файл не в /Apps/ или имя длиннее 8 символов.
- Ошибка Lua — скрипт собран под другой API; перегенерируй этим генератором.
